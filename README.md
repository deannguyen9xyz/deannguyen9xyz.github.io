# deannguyen9xyz.github.io

Source of the academic website of **Vu Bao Chau Nguyen**: https://deannguyen9xyz.github.io

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (MIT licence) and deployed by GitHub Actions on every push to `main`.

## Where things are

| What | File or folder |
|---|---|
| Name, sidebar text, email, links | `_config.yml` |
| Top menu | `_data/navigation.yml` |
| Home page | `_pages/about.md` |
| CV page | `_pages/cv.md` |
| Publications (one file per paper) | `_publications/` |
| Projects | `_portfolio/` |
| Profile photo | `images/profile.jpg` |
| Downloadable files (PDFs) | `files/` |
